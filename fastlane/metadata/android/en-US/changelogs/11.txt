Crash reporting is now opt-in, and the security check can be turned off.

Earlier versions sent a crash report automatically. They no longer do. The app
asks once, on first run, listing exactly what a report carries, and you can
change the answer any time in Settings > Support.

Settings > Security > Check interval now offers Never. It stops the scheduled
certificate check and the one that runs when the tunnel connects, so public
transparency logs are queried only if you want them to be.
